# Synoptic Meteorology Case Study: May 24, 2011 Tornado Outbreak

## Project Overview

This project examines the synoptic-scale environment associated with the May 24, 2011 tornado outbreak. Using upper-air reanalysis data and Python-based visualizations, the project investigates the atmospheric conditions associated with the El Reno–Piedmont EF5 tornado.

## Objectives

- Analyze upper-level flow and the jet stream at 250 hPa.
- Examine geopotential heights and vorticity at 500 hPa.
- Examine dew points and specific humidity 850 hPa.
- Analyze surface temperatures, dew points, and atmospheric conditions.
- Evaluate severe-weather ingredients, including CAPE and 0–6 km bulk wind shear.

## Tools and Technologies

- Python
- MetPy
- Matplotlib
- ERA5 reanalysis data
